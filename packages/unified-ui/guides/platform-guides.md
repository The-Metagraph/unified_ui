# Platform Guides

UnifiedUi supports three renderer targets. Use these focused references:

- [Terminal guide](platforms/terminal.md)
- [Desktop guide](platforms/desktop.md)
- [Web guide](platforms/web.md)

All platforms consume the same DSL/IUR tree and differ only in adapter conversion and event ingress.
